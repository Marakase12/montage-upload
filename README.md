# Montage Upload Service

Страница для загрузки больших исходников. Поддерживает локальный режим и облачную схему GitHub Pages → Timeweb App Platform → Timeweb S3.

Облачный режим также поддерживает MontageAI pipeline: сайт сохраняет задачу в S3,
локальная Windows-машина забирает MP4 через защищённый worker API, отправляет на
сайт стадии обработки и загружает готовый preview обратно в S3. На сайте можно
написать составную правку обычным текстом и явно подтвердить выбранный preview.
Подтверждение создаёт локальный `final.mp4`, но никогда не запускает публикацию.

## Запуск

```powershell
cd X:\AI\montage\upload-service
npm start
```

После запуска откройте `http://127.0.0.1:3020`.

Файлы передаются частями по 8 МБ, сохраняются без загрузки целого файла в память и могут быть продолжены после обрыва: достаточно снова выбрать тот же файл.

## Настройки

Переменные окружения:

- `PORT` — порт, по умолчанию `3020`.
- `HOST` — адрес, по умолчанию `127.0.0.1`. Для локальной сети можно установить `0.0.0.0`.
- `UPLOAD_DIR` — папка назначения, по умолчанию `X:\AI\montage\inbox` при текущем расположении проекта.
- `MAX_FILE_SIZE` — максимальный размер одного файла в байтах, по умолчанию 20 ГБ.
- `CHUNK_SIZE` — размер части в байтах, по умолчанию 8 МБ.
- `UPLOAD_TOKEN` — необязательный ключ доступа к API.

Пример запуска для локальной сети с ключом:

```powershell
$env:HOST = '0.0.0.0'
$env:UPLOAD_TOKEN = 'замените-на-длинный-случайный-ключ'
npm start
```

Пользователь вводит этот ключ через кнопку «Ключ доступа» на странице.

## Перед публикацией в интернете

Облачный backend находится в `timeweb-api`. Он создаёт временные сессии и подписанные multipart-ссылки, поэтому файлы передаются напрямую в Timeweb S3. Инструкция по переменным и деплою находится в `timeweb-api/README.md`.

Локальный bridge находится в рабочем MontageAI-проекте:

```text
X:\AI\Codex\montage\cloud_bridge.py
```

Ему нужны только URL облачного API и общий `WORKER_SECRET`. S3-ключи остаются
только на Timeweb и не копируются на Windows.

После заполнения двух локальных переменных мост можно установить в автозапуск:

```powershell
& 'X:\AI\Codex\montage\install_cloud_bridge_task.ps1'
```

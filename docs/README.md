## Как читать статусы

- **PROD** — есть отдельное подтверждение работы в развёрнутом сервисе.
- **LOCAL** — есть локальный код и проверки; это не означает deploy.
- **DEPLOYED** — код установлен, но полный production-сценарий этой задачи ещё не подтверждён.
- **TODO / WIP** — запланировано / выполняется.
- **GATE** — требуется согласование, доступ, бюджет или внешняя проверка.
- **Гипотеза** — предложение для проверки с клиентами, а не обещание продукта.

Бэклог — единая очередь задач. Планы раскрывают критерии готовности, но не ведут
вторую независимую копию статусов. Перед новым релизом обновлять результаты проверок,
известные ограничения и подтверждённую версию сервиса.

Здесь не хранятся ключи, пароли, реальные пользовательские ролики или персональные
данные клиентов. Ссылки на локальные папки — только карта разработки, не параметры
будущего сервера. Секреты никогда не должны попадать в Markdown или Git.
